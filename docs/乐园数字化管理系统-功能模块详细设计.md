# 模块一：实时经营数据中心

> 系统的「眼睛」—— 让管理者随时看清乐园全貌

## 1.1 模块概述

| 项目 | 说明 |
|------|------|
| **模块定位** | 乐园经营数据的统一采集、实时聚合与可视化展示 |
| **核心价值** | 替代店长"统筹全局"的能力，总部远程即可掌握全局经营状况 |
| **使用角色** | 总部管理员（全量数据）、区域负责人（本区域数据）、协同管理员（只读） |
| **优先级** | P0 — 系统基础，所有模块依赖此模块的数据 |

## 1.2 页面清单

| 编号 | 页面名称 | 说明 | 终端 |
|------|---------|------|------|
| D-01 | 经营总览大屏 | 全乐园核心指标一屏呈现 | PC / 大屏 |
| D-02 | 区域详情页 | 单个区域的完整经营数据 | PC / 移动端 |
| D-03 | 品类下钻页 | 区域内各品类/项目明细 | PC / 移动端 |
| D-04 | 对比分析页 | 多维度数据对比（时间/区域/活动） | PC |
| D-05 | 数据录入页 | 手工录入/修正经营数据 | PC / 移动端 |
| D-06 | 报表导出页 | 自定义时间范围导出 Excel/PDF | PC |

#### 数据卡片字段明细

| 字段 | 数据源 | 计算规则 | 刷新频率 |
|------|--------|---------|---------|
| 今日总营收 | revenue_records | SUM(amount) WHERE record_time = TODAY | 实时（5分钟） |
| 今日客流 | visitor_records | COUNT(DISTINCT visitor_id) WHERE date = TODAY | 实时（5分钟） |
| 客单价 | 计算字段 | 今日总营收 / 今日客流 | 随营收/客流刷新 |
| 较昨日同期 | revenue_records | (今日截至当前时刻 - 昨日同时刻) / 昨日同时刻 × 100% | 实时 |
| 区域营收 | revenue_records | SUM(amount) WHERE zone_id = X AND date = TODAY | 实时 |
| 区域占比 | 计算字段 | 区域营收 / 总营收 × 100% | 实时 |
| 区域客流 | visitor_records | COUNT WHERE zone_id = X AND date = TODAY | 实时 |

#### 状态指示规则

| 状态 | 条件 | 颜色 |
|------|------|------|
| 🟢 表现优秀 | 较昨日同期 ≥ +5% | 绿色 |
| 🟡 需要关注 | 较昨日同期在 -5% ~ +5% 之间，或连续2天下降 | 黄色 |
| 🔴 异常警告 | 较昨日同期 ≤ -5%，或连续3天下降 | 红色 |

### 【D-05】数据录入页

#### 录入方式

| 方式 | 说明 | 适用场景 |
|------|------|---------|
| **POS对接（自动）** | 与收银系统API对接，数据自动同步 | 首选方案，已有POS系统时 |
| **手工录入** | 负责人通过表单逐条录入 | POS未对接、数据修正时 |
| **批量导入** | 上传Excel模板批量导入 | 历史数据补录 |
| **扫码录入** | 移动端扫描小票快速录入 | 移动场景快速录入 |

#### 手工录入表单

| 字段 | 类型 | 必填 | 校验规则 | 说明 |
|------|------|------|---------|------|
| 区域 | 下拉选择 | 是 | 负责人只能选自己管辖的区域 | 自动带出当前负责人区域 |
| 品类 | 级联选择 | 是 | 随区域联动可选品类 | 支持多级选择 |
| 金额 | 数字输入 | 是 | > 0，保留2位小数 | 单笔金额 |
| 数量 | 数字输入 | 否 | ≥ 1 的整数 | 默认1 |
| 时间 | 日期时间 | 是 | 不能早于昨日、不能晚于当前 | 默认当前时间 |
| 备注 | 文本 | 否 | ≤ 200字 | 特殊说明 |

#### 数据修正规则

- 当日数据可直接修改，保留修改记录
- 隔日数据需提交修正申请，总部审批后生效
- 所有修改留有审计日志：修改人、修改时间、修改前值、修改后值

## 1.4 数据采集方案

### POS系统对接

```
┌──────────┐    API/Webhook     ┌──────────────┐
│  POS系统  │ ──────────────→  │   数据网关     │
│ (收银机)  │  每笔交易实时推送   │  数据清洗&校验  │
└──────────┘                   └──────┬───────┘
                                      │
                                      ▼
                               ┌──────────────┐
                               │  revenue_records │
                               │  (营收记录表)     │
                               └──────┬───────┘
                                      │ 定时聚合(每5分钟)
                                      ▼
                               ┌──────────────┐
                               │  revenue_daily  │
                               │  (日汇总表)      │
                               └──────────────┘
```

### 数据同步策略

| 场景 | 策略 | 延迟 |
|------|------|------|
| POS实时推送 | 每笔交易Webhook推送，写入明细表 | < 10秒 |
| 看板刷新 | 每5分钟从明细表聚合到缓存 | ≤ 5分钟 |
| 日汇总 | 每日凌晨1:00自动汇总前日数据 | T+1 |
| 手工录入 | 录入后即时入库 | 即时 |

## 1.5 关键业务规则

| 编号 | 规则 | 说明 |
|------|------|------|
| BR-D01 | 营业日定义 | 每日营业时间 09:00-22:00，超过22:00的交易计入次日 |
| BR-D02 | 退款处理 | 退款金额从当日营收中扣除，退款记录独立标记 |
| BR-D03 | 跨区消费 | 如套票涉及多区域，按预设比例分摊到各区域 |
| BR-D04 | 零营收预警 | 营业时间内某区域超过2小时无数据，触发异常提醒 |
| BR-D05 | 数据可见范围 | 区域负责人只能看到本区域数据，总部可看全部 |

# 模块二：任务派发与跟踪中心

> 系统的「手臂」—— 让决策高效落地，替代店长的执行调度能力

## 2.1 模块概述

| 项目 | 说明 |
|------|------|
| **模块定位** | 总部→区域负责人的闭环任务管理工具，实现决策快速落地 |
| **核心价值** | 替代店长"下达指令+盯执行"的能力，去店长化的核心模块 |
| **使用角色** | 总部管理员（创建/派发）、区域负责人（接收/执行/反馈）、系统（自动任务） |
| **优先级** | P0 — 去店长化的关键支撑 |

## 2.2 页面清单

| 编号 | 页面名称 | 说明 | 终端 |
|------|---------|------|------|
| T-01 | 任务看板（总部视角） | 全局任务总览，按状态/区域/类型筛选 | PC |
| T-02 | 任务创建页 | 创建并派发新任务 | PC / 移动端 |
| T-03 | 任务详情页 | 单个任务的完整信息和跟踪记录 | PC / 移动端 |

### 【A-04】活动效果看板

#### 核心指标

| 指标 | 计算公式 | 说明 |
|------|---------|------|
| **提升率** | (活动期日均 - 基线日均) / 基线日均 × 100% | 核心效果指标 |
| **目标达成率** | 当前提升率 / 目标提升率 × 100% | 是否达标 |
| **累计增量营收** | Σ(活动每日营收 - 基线日均) | 活动带来的额外收入 |
| **预估ROI** | (累计增量营收 - 已使用预算) / 已使用预算 × 100% | 投入产出比 |
| **日均客流增量** | 活动期日均客流 - 基线日均客流 | 引流效果 |
| **客单价变化** | 活动期客单价 - 基线客单价 | 消费深度变化 |

#### 基线计算方法

| 基线类型 | 计算方式 | 使用场景 |
|---------|---------|---------|
| **默认基线** | 活动前14天的日均值 | 通用 |
| **同类型日基线** | 活动前4周同一星期几的均值 | 受周末效应影响大时 |
| **去年同期** | 去年同一时段日均值 | 有去年数据时 |
| **自定义基线** | 用户手动指定参照时段 | 特殊情况 |

## 5.2 消息通知体系

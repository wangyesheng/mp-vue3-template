【阶段1：库存管理】
┌──────────┐
│ 商家入库 │ → 记录：型号、规格、SN批次号、工厂代码
└────┬─────┘ 自动记录：入库时间、操作员
│
│ （管理员可设置成本价格）
│
↓
┌──────────┐
│ 库存管理 │ → 实时库存、金额统计
└──────────┘

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

【阶段2：订单创建】
┌──────────┐
│ 商家录入 │
│ 基础信息 │
└────┬─────┘
│
├─ 选择购买平台（京东/淘宝/抖音等）
├─ 选择产品品类（玻璃膜/车衣/其他）
├─ 录入产品信息
│ ├─ 型号、SN批次号
│ ├─ 车型
│ ├─ 购买价格
│ ├─ 施工门店编号（或"无需施工"）
│ ├─ 工时价格（如有门店）
│ ├─ 临时手机号
│ └─ 消费者地址
│
├─ 【特殊】玻璃膜额外录入
│ └─ 多部位SN号（前挡/驾驶位/后座/后档）
│
↓
┌──────────┐
│ 系统生成 │ → 会员号（A001、A002...A999、B001...）
│ 会员号 │ → 发送短信/二维码给消费者
└────┬─────┘
│
↓
┌──────────┐
│ 库存出库 │ → 自动扣减对应SN批次号库存
└────┬─────┘ 玻璃膜按分切规格出库
│ 记录：出库时间、操作员
↓

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

【阶段3：消费者激活】
┌──────────┐
│ 消费者 │ → 扫描二维码/点击短信链接
│ 收到产品 │
└────┬─────┘
↓
┌──────────┐
│ 首次登录 │ → 输入会员号 + 默认密码（临时手机号）
└────┬─────┘
↓
┌──────────┐
│ 补充信息 │
└────┬─────┘
│
├─ 输入真实手机号（替换临时号码）
├─ 修改登录密码
├─ 输入推荐码（可选）
│ └─ 推荐人和被推荐人都获得额外积分
│
↓
判断：是否需要施工？
│
├─【无需施工】────────────────────┐
│ ↓ │
│ 直接显示质保信息 │
│ 积分到账（订单金额1:1） │
│ │
└─【需要施工】 │
↓ │
┌──────────┐ │
│ 显示门店 │ │
│ 联系方式 │ │
└────┬─────┘ │
│ │
├─ 提示：联系门店预约时间 │
└─ 门店端同步显示待施工订单 │
│
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━│━━━━━━━━

【阶段4：门店施工】（如需施工） │
┌──────────┐ │
│ 消费者 │ → 联系门店预约 │
│ 到店 │ │
└────┬─────┘ │
↓ │
┌──────────┐ │
│ 门店施工 │ │
└────┬─────┘ │
↓ │
┌──────────┐ │
│ 施工完成 │ │
└────┬─────┘ │
│ │
├─ 门店登录系统 │
├─ 打开对应订单 │
├─ 点击"施工完成" │
├─ 上传完工图片 │
│ ├─ 前/中/后 3张 │
│ └─ 车架号特写 1张 │
├─ 参考示例图片 │
│ │
↓ │
┌──────────┐ │
│ 订单状态 │ → 变更为"待消费者确认" │
│ 更新 │ │
└────┬─────┘ │
│ │
↓ │
│
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━│━━━━━━━━

【阶段5：消费者确认】←──────────────────┘
┌──────────┐
│ 消费者 │ → 再次登录（会员号+密码）
│ 再次登录 │
└────┬─────┘
↓
┌──────────┐
│ 补充订单 │
│ 信息 │
└────┬─────┘
│
├─ 输入车牌号
├─ 输入车架号
├─ 确认完工图片无误
│
↓
┌──────────┐
│ 门店评分 │
└────┬─────┘
│
├─ 环境评分（1-5星）
├─ 服务评分（1-5星）
├─ 技术评分（1-5星）
│
↓
┌──────────┐
│ 确认提交 │ → 二次确认信息无误
└────┬─────┘
↓
┌──────────┐
│ 质保完结 │
└────┬─────┘
│
├─ 积分到账
│ ├─ 订单积分（订单金额1:1）
│ └─ 推荐奖励积分（如有推荐码）
│
├─ 奖励金额计算（门店端）
│ ├─ 根据评分计算
│ └─ 3星及以上才有奖励
│
└─ 质保信息锁定（消费者不可再修改）

【阶段6：售后服务】（如有问题）
┌──────────┐
│ 消费者 │ → 登录质保页面
│ 申请售后 │
└────┬─────┘
│
├─ 点击"申请售后"
├─ 输入联系信息
├─ 描述问题
├─ 上传图片
│
↓
┌──────────┐
│ 商家端 │ → 收到售后提醒
│ 接收售后 │
└────┬─────┘
│
├─ 查看售后详情
├─ 联系客户沟通
├─ 输入处理方案
│
↓
判断处理方式？
│
├─【补发产品】──────────────┐
│ ↓ │
│ 录入补发产品信息 │
│ 录入SN批次号 │
│ 库存自动扣减 │
│ 同步到售后时间线 │
│ │
└─【更换门店】 │
↓ │
选择：原门店工时回收？ │
├─ 是：扣除原工时 │
└─ 否：保留原工时 │
录入新门店工时 │
│
↓ │
┌──────────┐ │
│ 售后完结 │←─────────────────────┘
└────┬─────┘
│
├─ 消费者端查看处理结果（时间线）
├─ 该订单门店奖励金额取消
│ └─ 如已结算，显示负数
│
└─ 门店售后率统计更新

【阶段7：结算管理】
┌──────────┐
│ 门店端 │ → 查看待结算金额
│ 查看 │ ├─ 工时费用
└────┬─────┘ └─ 奖励金额（商家回访确认后显示）
│
↓
┌──────────┐
│ 商家端 │ → 按月统计门店数据
│ 结算 │
└────┬─────┘
│
├─ 查看门店工时明细
├─ 查看奖励金额明细
├─ 录入感谢金额（手动）
├─ 确认无误后点击"已结算"
│
↓
┌──────────┐
│ 结算完成 │ → 状态锁定，不可修改
└────┬─────┘ 门店端显示"已结算"
│
↓
┌──────────┐
│ 财务报表 │ → 统计模块查看
└──────────┘
│
├─ 订单统计（按日期/按状态/按SN）
├─ 库存统计（数量/金额）
└─ 毛利润统计
├─ 订单总金额
├─ 施工成本（工时）
└─ 门店奖励支出

# rpx 响应式单位原理

## 什么是 rpx

`rpx` 是微信小程序的**响应式像素单位**，它会根据屏幕宽度**自动换算**，实现不同设备上的自适应布局。

---

## 核心规则

微信规定：**屏幕宽度固定为 750rpx**

无论实际屏幕多宽，都会被映射为 750rpx。

---

## 换算公式

```
1rpx = 屏幕实际宽度(px) / 750

实际像素 = rpx值 × (屏幕宽度 / 750)
```

---

## 换算示例

以 `680rpx × 340rpx` 的元素为例：

| 屏幕宽度 (px) | 1rpx = ? px | 680rpx = ? px | 340rpx = ? px |
| ------------- | ----------- | ------------- | ------------- |
| 750px         | 1px         | 680px         | 340px         |
| 640px         | 0.853px     | 580px         | 290px         |
| 375px (iPhone 6/7/8) | 0.5px | 340px         | 170px         |
| 414px (iPhone Plus)  | 0.552px | 375px       | 188px         |
| 390px (iPhone 12/13) | 0.52px | 354px        | 177px         |

---

## 为什么不同尺寸显示效果一致？

因为 **rpx 是按比例缩放的**，元素在屏幕中的**占比**始终相同。

### 计算比例

```
680rpx / 750rpx = 90.67% 的屏幕宽度
```

### 不同屏幕的验证

| 屏幕宽度 | 元素实际宽度 | 占屏幕比例 |
| -------- | ------------ | ---------- |
| 750px    | 680px        | 680 ÷ 750 = **90.67%** |
| 640px    | 580px        | 580 ÷ 640 = **90.67%** |
| 375px    | 340px        | 340 ÷ 375 = **90.67%** |

**像素值不同，但占屏幕的比例相同，所以视觉效果一致！**

## 设计稿建议

| 建议 | 说明 |
| ---- | ---- |
| 设计稿宽度 | 使用 **750px** 宽度 |
| 标注单位 | 设计稿上 1px = 代码中 1rpx |
| 直接使用 | 设计稿标注多少 px，代码写多少 rpx |

### 示例

设计稿标注：`width: 680px, height: 340px`

代码直接写：

```css
.box {
  width: 680rpx;
  height: 340rpx;
}
```

---

## rpx vs px vs vw

| 单位 | 特点 | 适用场景 |
| ---- | ---- | -------- |
| `rpx` | 相对于 750 宽度自适应 | 小程序推荐使用 |
| `px` | 固定像素，不会缩放 | 需要固定尺寸的元素（如 1px 边框） |
| `vw` | 相对于视口宽度的百分比 | H5 页面 |

### 对比

```css
/* rpx: 自适应 */
width: 375rpx;  /* 始终占屏幕 50% */

/* px: 固定 */
width: 375px;   /* 固定 375 像素，不同屏幕占比不同 */

/* vw: 百分比 */
width: 50vw;    /* 始终占屏幕 50% */
```

---

## 注意事项

### 1. 小数像素问题

rpx 换算后可能出现小数，会被四舍五入，可能导致 1px 的误差。

```
640px 屏幕: 1rpx = 0.853px
实际渲染时会取整，可能有细微偏差
```

### 2. 边框建议用 px

1rpx 在某些屏幕上可能小于 1px，导致边框显示不出来：

```css
/* ❌ 可能显示不出来 */
border: 1rpx solid #ccc;

/* ✅ 推荐 */
border: 1px solid #ccc;
```

### 3. 字体大小

字体大小可以用 rpx，但建议设置最小值：

```css
font-size: 28rpx;  /* 在 375px 屏幕上约 14px */
```

## 1. 项目概述

### 1.1 项目背景

打造一个视频教程付费小程序，用户需要付费才能观看视频教程。系统支持多种收费模式，包括单视频购买、会员订阅等，并可根据视频画质和时长设置不同的价格档位。

### 1.2 核心目标

- 提供流畅的视频播放体验
- 灵活的多层级收费体系
- 安全的支付与视频防盗机制
- 便捷的后台内容管理

### 1.3 技术选型

| 层级     | 技术方案                    |
| -------- | --------------------------- |
| 前端框架 | uni-app + Vue3              |
| UI组件库 | NutUI-UniApp                |
| 状态管理 | Pinia                       |
| 样式方案 | TailwindCSS + SCSS          |
| 视频服务 | 腾讯云点播 / 阿里云视频点播 |
| 支付     | 微信支付                    |
| 后端建议 | Node.js / Java / Go         |
| 数据库   | MySQL + Redis               |

## 4. 核心模块设计

### 4.1 收费体系设计

#### 4.1.1 单视频收费

```javascript
// 单视频定价模型
const videoPricing = {
  videoId: 'v001',
  basePrice: 9.9, // 基础价格（标清）
  qualityPricing: {
    sd: 0, // 标清：基础价格
    hd: 5, // 高清：+5元
    fhd: 10 // 超清：+10元
  },
  durationPricing: {
    // 时长系数
    short: 1.0, // <30分钟：1倍
    medium: 1.5, // 30-60分钟：1.5倍
    long: 2.0 // >60分钟：2倍
  }
  // 最终价格 = basePrice × durationCoefficient + qualityExtra
}
```

| 套餐类型 | 价格   | 有效期 | 权益                         |

| 季度会员 | ¥79.9  | 90天   | 高清画质、全部课程           |
| 年度会员 | ¥199.9 | 365天  | 超清画质、全部课程、专属内容 |

## 5. 数据库设计

### 5.1 核心表结构

#### 5.1.1 用户表 (users)

```sql
CREATE TABLE users (
  id BIGINT PRIMARY KEY AUTO_INCREMENT,
  openid VARCHAR(64) UNIQUE NOT NULL COMMENT '微信openid',
  unionid VARCHAR(64) COMMENT '微信unionid',
  nickname VARCHAR(64) COMMENT '昵称',
  avatar VARCHAR(255) COMMENT '头像',
  phone VARCHAR(20) COMMENT '手机号',
  member_level TINYINT DEFAULT 0 COMMENT '会员等级：0普通用户 1月度 2季度 3年度 4终身',
  member_expire_time DATETIME COMMENT '会员到期时间',
  balance DECIMAL(10,2) DEFAULT 0 COMMENT '账户余额',
  status TINYINT DEFAULT 1 COMMENT '状态：0禁用 1正常',
  created_at DATETIME DEFAULT CURRENT_TIMESTAMP,
  updated_at DATETIME DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP,
  INDEX idx_openid (openid),
  INDEX idx_phone (phone)
) COMMENT '用户表';
```

#### 5.1.2 视频分类表 (video_categories)

```sql
CREATE TABLE video_categories (
  id INT PRIMARY KEY AUTO_INCREMENT,
  parent_id INT DEFAULT 0 COMMENT '父级ID',
  name VARCHAR(50) NOT NULL COMMENT '分类名称',
  icon VARCHAR(255) COMMENT '分类图标',
  sort INT DEFAULT 0 COMMENT '排序',
  status TINYINT DEFAULT 1 COMMENT '状态',
  created_at DATETIME DEFAULT CURRENT_TIMESTAMP,
  INDEX idx_parent (parent_id)
) COMMENT '视频分类表';
```

#### 5.1.3 视频表 (videos)

```sql
CREATE TABLE videos (
  id BIGINT PRIMARY KEY AUTO_INCREMENT,
  category_id INT NOT NULL COMMENT '分类ID',
  title VARCHAR(200) NOT NULL COMMENT '标题',
  description TEXT COMMENT '描述',
  cover_url VARCHAR(255) COMMENT '封面图',
  duration INT DEFAULT 0 COMMENT '时长（秒）',

  -- 视频文件（多画质）
  video_url_sd VARCHAR(255) COMMENT '标清视频URL',
  video_url_hd VARCHAR(255) COMMENT '高清视频URL',
  video_url_fhd VARCHAR(255) COMMENT '超清视频URL',

  -- 试看设置
  preview_duration INT DEFAULT 60 COMMENT '试看时长（秒）',
  preview_url VARCHAR(255) COMMENT '试看视频URL',

  -- 定价
  charge_type TINYINT DEFAULT 1 COMMENT '收费类型：0免费 1单独购买 2会员专享 3会员折扣',
  price_sd DECIMAL(10,2) DEFAULT 0 COMMENT '标清价格',
  price_hd DECIMAL(10,2) DEFAULT 0 COMMENT '高清价格',
  price_fhd DECIMAL(10,2) DEFAULT 0 COMMENT '超清价格',
  member_discount DECIMAL(3,2) DEFAULT 1.00 COMMENT '会员折扣',

  -- 标签
  difficulty TINYINT DEFAULT 1 COMMENT '难度：1入门 2进阶 3高级',
  tags VARCHAR(255) COMMENT '标签，逗号分隔',

  -- 统计
  view_count INT DEFAULT 0 COMMENT '观看次数',
  like_count INT DEFAULT 0 COMMENT '点赞数',
  collect_count INT DEFAULT 0 COMMENT '收藏数',
  buy_count INT DEFAULT 0 COMMENT '购买数',

  -- 状态
  status TINYINT DEFAULT 0 COMMENT '状态：0草稿 1审核中 2已上架 3已下架 4审核拒绝',
  publish_time DATETIME COMMENT '发布时间',

  created_at DATETIME DEFAULT CURRENT_TIMESTAMP,
  updated_at DATETIME DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP,

  INDEX idx_category (category_id),
  INDEX idx_status (status),
  INDEX idx_charge_type (charge_type),
  FULLTEXT INDEX idx_title (title)
) COMMENT '视频表';
```

#### 5.1.5 订单表 (orders)

```sql
  -- 订单类型
```

### 8.2 支付安全措施

1. **签名验证**：所有支付请求必须验证签名
2. **订单超时**：未支付订单30分钟自动取消
3. **幂等处理**：支付回调需要幂等处理，防止重复发货
4. **金额校验**：回调金额与订单金额必须一致
5. **状态机控制**：订单状态严格按照状态机流转

### 9.4 断点续播实现

```javascript
// useVideoProgress.js
export function useVideoProgress(videoId) {
  const lastPosition = ref(0)

  // 获取上次播放位置
  const getLastPosition = async () => {
    const res = await api.getWatchHistory(videoId)
    lastPosition.value = res.lastPosition || 0
    return lastPosition.value
  }

  // 保存播放进度（节流）
  const saveProgress = throttle(async (position, duration) => {
    await api.saveWatchProgress({
      videoId,
      position,
      duration,
      progress: ((position / duration) * 100).toFixed(2)
    })
  }, 10000) // 每10秒保存一次

  // 页面离开时保存
  onUnmounted(() => {
    // 立即保存当前进度
    saveProgress.flush()
  })

  return {
    lastPosition,
    getLastPosition,
    saveProgress
  }
}
```

```javascript
// config/index.js
export default {

  // API地址

    process.env.NODE_ENV === 'production'
      ? 'https://api.example.com/v1'

      1: '月度会员',

  }
}
```
